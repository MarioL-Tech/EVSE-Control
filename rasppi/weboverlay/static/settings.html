Darstellung

Die Auswahl gilt nur in diesem Browser.

Als WebApp verwenden

Die Installationshilfe benötigt JavaScript. Eine manuelle Homescreen-Verknüpfung hängt vom Browser ab.

Aktualisierungen benötigen eine Verbindung zur Website.

  1. Die Website über HTTPS öffnen. Bei lokaler Zertifizierungsstelle deren Stammzertifikat zuerst auf dem Gerät als vertrauenswürdig einrichten. Zertifikatswarnungen nicht umgehen.
  2. Android/Chrome: im Browsermenü „App installieren“ oder „Zum Startbildschirm hinzufügen“ wählen, sofern angeboten.
  3. iPhone/iPad: in Safari „Teilen“ und „Zum Home-Bildschirm“ wählen; je nach Version „Als Web-App öffnen“ aktivieren.

Dies ist die Website im eigenen Fenster, keine native App. Messwerte benötigen eine Verbindung. Offline erscheint nur ein Hinweis, keine gespeicherten Livewerte. Eine neue Version wird nach dem Schließen aller App-Fenster und Website-Tabs aktiv; danach erneut öffnen.

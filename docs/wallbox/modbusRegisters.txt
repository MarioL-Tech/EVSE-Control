register (400Eh) returns all limits of charging current
         (4020h) returns limit of charging current set by Modbus

register (4100h) provides an option to set charging current limit 
Pause state when the current limit is less than 6A. 
After that when current limit is set above 6A, then charging session will be resumed. 
The choice of 6A is derived from IEC 61851-1

register (4103h) Cable connector
0: Unlock connector, !regardless of charging state (400Ch)!
1: Lock connector

register (4105h) Start / Stop Charging 
0: stop charging
1: start charging
for pausing see register (4100h)
